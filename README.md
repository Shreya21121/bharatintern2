# bharatintern assignment -2
temperature convertor

Temperature Conversion between Celsius & Fahrenheit using HTML CSS & JavaScript. The Temperature is generally measured in terms of unit degree., i.e. in degrees centigrade, in degrees & Fahrenheit.

Celsius is a standard unit of temperature on the Celsius scale, & is represented by the °C symbol.
Fahrenheit uses the degree Fahrenheit as the unit & is represented with the °F symbol.
